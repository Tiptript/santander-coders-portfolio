# 🧠 Exercícios Resolvidos - Lógica, Algoritmos e Programação Funcional

Coleção de exercícios práticos resolvidos durante o programa **Santander Coders**, cobrindo desde manipulação de strings e formatos tabulares até paradigmas de programação funcional e tratamento defensivo de exceções.

---

## 📚 Tópicos e Exercícios Abordados

| # | Função / Algoritmo | Paradigma / Conceito | Descrição |
| :-: | :--- | :--- | :--- |
| **1** | `produto_mais_vendido` | Parsing de Strings & Dicionários | Lê formato CSV bruto em string e identifica o produto com maior volume comercializado. |
| **2** | `media_vendas` | Aritmética & Iteração | Calcula o montante financeiro total multiplicando quantidades e valores unitários. |
| **3** | `ger_reduce` | Programação Funcional (`map` + `reduce`) | Implementação do padrão MapReduce para computar a soma dos quadrados de uma coleção. |
| **4** | `div2` | Funções de Alta Ordem (`filter` + `lambda`) | Filtragem de números pares utilizando predicados anônimos. |
| **5** | `numeros_div_7` | Compreensão de Listas & Conjuntos (`set`) | Extração de elementos únicos divisíveis por 7 retornados de forma ordenada. |
| **6** | `cria_arquivo_json` | Serialização & `zip` | Emparelhamento de chaves e valores com conversão para JSON estruturado. |
| **7** | `contar_frequencia_caracteres` | Dicionários & Frequências | Base conceitual para Bag-of-Words e processamento de linguagem natural. |
| **8** | `gerar_dicionario_fatoriais` | Recursão / Algoritmos Clássicos | Geração de tabela de fatoriais até $k$ em estrutura de dicionário. |
| **9** | `divide_dois_numeros` | Tratamento de Exceções (`try`/`except`) | Captura e segregação de erros (`ZeroDivisionError` e `TypeError`). |

---
